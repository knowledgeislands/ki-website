# Guides

Practical instructions for operating and maintaining the Knowledge Islands website. Decision Records explain why, specifications explain what, these guides explain how.

Guides are grouped by the audience that reads them. This collection currently serves one audience: the developer who maintains the site. Reader-facing guidance for people using Knowledge Islands is not held here — it is published content, held under the project it is about ([`apps/site/src/projects/<slug>/`](../../apps/site/src/projects/)), or — when it belongs to no project — under [`apps/site/src/prompting/`](../../apps/site/src/prompting/) and [`apps/site/src/optional-tools/`](../../apps/site/src/optional-tools/). [Deciding what this site publishes](developer/what-to-publish.md) governs what belongs there, and [project guides](developer/project-guides.md) governs the shape each page takes.

- [Developer guides](developer/README.md) — deployment, the generated route registries, and the rules for publishing and refreshing a page on this site.
