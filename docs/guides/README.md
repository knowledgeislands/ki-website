# Guides

Practical instructions for operating and maintaining the Knowledge Islands website. Decision Records explain why, specifications explain what, these guides explain how.

Guides are grouped by the audience that reads them. This collection currently serves one audience: the developer who maintains the site. Reader-facing guidance for people using Knowledge Islands is not held here — it is published content, held in a Docs section under [`apps/site/src/docs/<section>/`](../../apps/site/src/docs/). [Deciding what this site publishes](developer/what-to-publish.md) governs what belongs there, and [Docs sections](developer/docs-sections.md) governs the shape each page takes.

- [Developer guides](developer/README.md) — deployment, the generated route registries, and the rules for publishing and refreshing a page on this site.
