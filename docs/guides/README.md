# Guides

Practical instructions for operating and maintaining the Knowledge Islands website. Decision Records explain why, specifications explain what, these guides explain how.

Guides are grouped by the audience that reads them. This collection currently serves one audience: the developer who maintains the site. Reader-facing guidance for people using Knowledge Islands is not held here — it is published content under [`apps/site/src/guidance/`](../../apps/site/src/guidance/), and [Deciding what this site publishes](developer/guidance-ownership.md) governs what belongs there.

- [Developer guides](developer/README.md) — deployment, the generated route registries, and the rules for publishing and refreshing site guidance.
